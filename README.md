# ArcvelleOS organization profile

This repository contains the public GitHub profile for [ArcvelleOS](https://github.com/ArcvelleOS).

- `profile/README.md` appears on the organization's Overview page when this repository is published as **public** with the exact name `.github`.
- `profile/assets/arcvelle-mark.svg` is the editable logo.
- `profile/assets/arcvelle-avatar.png` is a square image ready for the organization avatar setting.
- `profile/assets/banner-small.svg` is the editable compact banner source; `banner-small.png` is used in the profile.
- `profile/assets/banner.svg` and `banner.png` are the larger banner variant.

The organization avatar is set in GitHub organization settings; adding the image to this repository alone does not change the avatar.
